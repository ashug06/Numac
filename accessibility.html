Accessibility statement

Numac Healthcare intends this website to meet Web Content Accessibility Guidelines (WCAG) 2.2 Level AA. Healthcare information that people cannot perceive, operate, or understand is not healthcare information.

What is already in place

  • Semantic HTML, one H1 per page, and labelled landmarks (banner, navigation, main, contentinfo).
  • A skip link to main content on every page.
  • Visible focus indicators that meet 3:1 contrast against adjacent colours.
  • Text and UI contrast aimed at 4.5:1 for body copy; a high-contrast mode and larger-text control that persist in your browser.
  • Keyboard operation for primary navigation, including Escape to close menus.
  • Form fields with visible labels, autocomplete where appropriate, and errors that do not rely on colour alone.
  • Target sizes of at least 24 by 24 CSS pixels for controls, with 44 pixel-class primary buttons.
  • Respect for prefers-reduced-motion and support for browser zoom to 200%.
  • Text alternatives for meaningful images; decorative graphics marked so assistive technology can ignore them.

Known limits

Third-party fonts load from Google Fonts; if that network is blocked, system fonts remain. Enquiry forms currently confirm on the device and still need a server endpoint in production. Map links go to OpenStreetMap rather than an inaccessible unlabeled iframe.

How to report a barrier

Email numachealthcare@yahoo.com with the page address, the assistive technology you use, and what you expected to happen. We treat accessibility defects as defects, not as feedback to file away.

Conformance status

This site is partially conformant with WCAG 2.2 AA: we designed and built to the success criteria listed above, and we welcome independent audit. Conformance is not a one-time badge.
